# Escuela de Patinaje

Aplicación web para una escuela de patinaje: sitio público (programas, sedes, horarios, instructores, preinscripción) y panel administrativo.

**Stack:** React + Vite + TypeScript + Tailwind CSS + shadcn/ui + Supabase + Vercel + PWA.

## Documentación

El desarrollo sigue el [Plan Maestro v3](plan_maestro_escuela_patinaje_v3.md) (54 pasos en 6 sprints).

## Estado

Sprint 0 — Base y despliegue (en progreso).

## Convenciones

- Código en inglés, interfaz en español.
- Ramas `feature/*` y `fix/*`; `main` solo por Pull Request.
- Commits convencionales (`feat:`, `fix:`, `docs:`, `db:`).
- Nunca subir secretos: usar `.env.local` y `.env.example`.
